# Portfólio Pessoal (Protótipo)

Protótipo de portfólio pessoal, desenvolvido inicialmente no Figma, com o objetivo de explorar ideias de design, identidade visual e estruturação de uma futura página pessoal.

## Sobre o conteúdo

Este projeto reúne algumas informações sobre mim, Arthur, apresentadas de uma maneira mais criativa e, em alguns momentos, propositalmente "sensacionalista". A ideia é experimentar diferentes formas de apresentar minha trajetória, habilidades e interesses, sem necessariamente tratar todo o conteúdo como uma representação formal ou definitiva.
